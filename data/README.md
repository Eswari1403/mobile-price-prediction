# Dataset Information

## Project
Mobile Price Prediction

## Dataset Description
The dataset contains mobile phone specifications used to predict mobile price ranges through machine learning classification models.

## Features Used
- RAM
- Battery Capacity
- Camera Specifications
- Processor Specifications

## Target Variable
- Price Range

## Data Preprocessing
The dataset was cleaned and prepared by handling missing values, checking data consistency, and selecting relevant features for model training.

## Data Source
The original dataset source and reference link will be documented here.
https://www.kaggle.com/datasets/iabhishekofficial/mobile-price-classification

The dataset is not stored in this folder. This folder contains dataset-related documentation only. The original dataset is used for data analysis, feature engineering, and model development.
